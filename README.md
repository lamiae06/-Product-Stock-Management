# Product Stock Management

A simple C++ application for managing products and stock.

## Features

- Product management
- Stock management
- Product sales
- Stock replenishment
- Expiration date validation
- Stock value calculation
- Unique product IDs
- Copy constructor
- Date comparison

## Technologies

- C++
- C++17

## Structure

- `Date.h / Date.cpp` — Date management
- `Produit.h / Produit.cpp` — Product and stock management
- `main.cpp` — Program demonstration
